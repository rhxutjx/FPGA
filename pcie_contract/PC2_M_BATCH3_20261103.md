# PC2 M NPU batch=3 板测结果（2026-11-03）

状态：**PASS_M_BATCH3_ONE_ROUND**  
实现：B 的 `experimental_batch_generate` + `BatchRuntime` + 当前 functional M bit + PC2 v3 transport factory。  
M endpoint 仍单帧在途、Attention 逐请求；batch=3 只批量化 NPU linear，不是三 Attention 并行。

- batch：3

## 3. 解释

- 三条 session 的 Q/K/V、O、MLP、LM Head 用一次 `M=3` NPU MatMul；
- Attention 仍逐 session、单帧在途，因此不是三路 Attention 并行；
- 输出 token 与单 session 一致，说明这批输入/权重下 batch 语义一致；
- B 的 batch 原型此前只有 CPU/mock 测试；本次是真实 RKNN + functional M v3 的首次 batch3 板测（单轮）。

## 4. 边界

- 只有 **1 轮**，不是 30 轮；
- 没有 B bit，不能做 B/M 对比；
- 没有独立 full-model M golden；输出一致性只对三条已测 prompt；
- init 5.844 s 未计入 113.161 s；NPU contexts 已常驻；
- Attention 时间包含 transport 等待，不是 FPGA 周期；
- 不能把 0.212 当 batch3 + 三 Attention 并行结论。
